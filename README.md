# sceyenic

FORMAT-style photography portfolio for **sceyenic**.

## Categories

Street · Photojournalism · Graduation · Headshots · Event

## Develop

```bash
npm install
npm run dev
```

## Add photos

1. Drop images into `public/images/{category}/`
2. Register them in `src/data/portfolio.ts`

## Live

https://sceyenic.vercel.app
